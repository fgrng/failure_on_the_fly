{% if variante == "a" %}

A · heute. Aktiv: weisse Fläche, grüne Schrift (#2c512c), grüner Balken (#009b56). Hover: weisse Fläche, grüne Schrift. Entspricht ADR-0024 wörtlich. Dissonanz: gelbe Gruppe mit grünem Balken.

{% elif variante == "b" %}

B · Balken in Bereichsfarbe. Aktiv: nur der 3-px-Balken wechselt auf --color-area-*-solid, die Schrift bleibt grün. Hover unverändert grün. Kleinster Eingriff: Grün bleibt die Interaktionsfarbe, der Balken ist ein grafisches Element (WCAG 1.4.11, 3:1). Gelb-Dark auf Weiss: 4,42:1, Mint 4,71, Violett 8,79, Blau 7,44.

{% elif variante == "c" %}

C · Balken und Fläche im Bereichston. Aktiv: Fläche --color-area-*-tint, Balken -solid, Schrift neutral dunkel (#383836; auf Tint ≥ 8,3:1). Hover: halbe Tint-Fläche, aufgehellter Balken in Bereichsfarbe, dunkle Schrift, keine Unterstreichung. Grün verschwindet ganz aus der Navigation, darum müsste ADR-0024 »aktive Navigation« aus den grünen Akzenten streichen.

{% else %}

D · Gruppe als getönte Fläche. Die ganze Gruppe des aktiven Eintrags wird zur Tint-Fläche. Der Eintrag selbst ist weiss mit dunkler Schrift und einem Punkt in Bereichsfarbe, ohne Balken. Hover: weiss, dunkle Schrift. Der Bereich ist schon von Weitem sichtbar, der einzelne Eintrag ist aber schwächer markiert.

{% endif %}
